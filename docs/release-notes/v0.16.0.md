# Wealth Watcher v0.16.0

## Highlights

- The Dashboard Properties chart now shows a red Mortgage value line alongside property value and equity, making outstanding mortgage balances visible over the selected period.
- Mortgage values also appear in the chart legend, hover tooltips, and accessible trend data table.

## Fixes

- Fills the missing mortgage history in the Properties chart using property value minus equity at each point.
- Adds regression coverage for mortgage repayments, fully paid mortgages, and history with equity stored in the aggregate Value field.

## Upgrade notes

- No database migration or deployment configuration change is required.
- Back up PostgreSQL and the configured CONFIG_PATH Data Protection key directory before updating; back up relay data when delivery history matters.
- Pull the release images and recreate the affected services. Normal service restart downtime applies.
- To roll back, restore the v0.15.0 image tags or their immutable digests. There is no schema change to reverse; the mortgage chart line will no longer appear.

## Known issues

- Investment history recorded before v0.14.0 keeps only the last observation of each day, so Day-range charts for earlier dates remain flat.
- Wall-clock polling schedules follow the API host's local time and do not offer a separate per-connection time-zone setting.
- The application remains intended for a local or trusted network and has no built-in authentication, authorization, or tenant isolation.
